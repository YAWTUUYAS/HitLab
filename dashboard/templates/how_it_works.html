The lab manual

A real-time pipeline that decodes the formula behind viral music.

HitLab ingests trending tracks from 10 countries, fuses signals from three independent music APIs every minute, and surfaces tracks before they break out — using the same architectural patterns real music analytics teams run in production.

Where the data comes from

Three independent APIs. Different signal each. All free, no paid tier.

Last.fm
geo.getTopTracks
Top tracks per country with listener counts. The primary trending signal.
Free · API key
Deezer
/search
Streaming popularity rank (0–1M), preview URL, duration. Independent of Last.fm.
Free · no auth
iTunes
Search API
Genre + release date metadata. Adds editorial categorization.
Free · no auth
03

The hit formula

Four weighted signals on a 0–100 scale. Each one captures a different dimension of viral momentum.

hype_score = 0.30 · reach + 0.25 · geo_spread + 0.25 · deezer_rank + 0.20 · velocity
reachLast.fm log-scaled listeners
30%
geo_spreadCountries trending (out of 10)
25%
deezer_rankStreaming popularity 0–1M
25%
velocityΔ hype between snapshots
20%
velocity
Δ hype / cycle
Positive = climbing. Negative = cooling.
acceleration
Δ velocity / cycle
Detects the inflection point — when a track starts going viral.

05

How to read this dashboard

Three modes. Each one answers a different question about the music landscape.

A
Overview
"What's hot right now?"
Top tracks ranked by hype score · regional activity bars · momentum chart of the top 5 over the selected window.
B
Forecast
"What's about to blow up?"
Velocity × acceleration scatter. Top-right quadrant = emerging hits, bottom-left = burning out.
C
Track details
"How is this song evolving?"
Pick any track, see its hype curve, momentum profile (velocity + acceleration overlay), and country distribution.
Time slider at the top of every mode lets you replay any window since the pipeline started ingesting.
